SUNDER exposes Burp as an autonomous, authenticated offensive Model Context Protocol (MCP) server. It captures HTTP exchanges and WebSocket messages into session memory so AI assistants can follow live traffic, retrieve only the messages they need, and operate Burp programmatically.

For more information about the protocol, visit modelcontextprotocol.io

Note: Any data sent to external tools via this extension is subject to their data processing policies.

Features

  • Send HTTP/1.1 and HTTP/2 requests directly from AI clients with security controls
  • Access and filter proxy history (HTTP and WebSocket) with regex support
  • Generate and poll Burp Collaborator payloads for out-of-band testing (Professional only)
  • Create Repeater tabs and send requests to Intruder
  • Export and modify project and user configuration via JSON
  • Control proxy intercept, task execution engine, and message editor contents
  • Built-in encoding utilities (URL, Base64) and random string generation
  • Automatic Claude Desktop installation with packaged stdio proxy server
  • Session-only live capture across all Burp HTTP tools and WebSocket connections
  • Dedicated live traffic browser with search, raw message viewers, and Repeater handoff
  • Combined HTTP/WebSocket cursor feed, endpoint aggregation, and response-variant detection
  • Autonomous request replay, mutation, sending, cookie, Organizer, crawl, and audit actions
  • Bearer/API-key authentication enabled by default with token rotation
  • No extension traffic database; the in-memory buffer is discarded on unload
  • Burp scope and explicit target allowlists enforce autonomous action boundaries
  • Configurable target approval system for HTTP requests and history access
  • Interact with Organizer entries

Usage

  1. Navigate to the "SUNDER" tab and enable the MCP server.
  2. Configure Burp scope, auto-approve targets, autonomous mode, and configuration editing permissions.
  3. Use the installer button to automatically configure Claude Desktop, or manually configure your MCP client to connect to http://127.0.0.1:9987 (SSE mode) or use the packaged stdio proxy server.
  4. Interact with Burp through your AI client using the available MCP tools.
